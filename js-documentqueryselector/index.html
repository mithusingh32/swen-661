Introduction

  • HTML5 and JavaScript are essential for building modern user interfaces.
  • Today, we'll explore document.querySelector()—a powerful tool for selecting elements in the DOM.
  • We'll cover its purpose, usage, common patterns, and practical examples.

What is document.querySelector()?

  • A JavaScript method for selecting the first element that matches a CSS selector.
  • Lets you interact with HTML elements dynamically.
  • Works with any valid CSS selector (class, id, tag, attribute, etc.).
const element = document.querySelector('div.my-class');

Why Use querySelector()?

  • Simple, flexible way to find elements on the page.
  • Replaces older methods like getElementById() and getElementsByClassName() for many use cases.
  • Supports complex CSS selectors for precise targeting.

Syntax Overview

document.querySelector(selector);
  • selector: A string containing one or more CSS selectors.
  • Returns the first matching element, or null if none found.

Common Selectors

  • '#id' — Select by ID
  • '.class' — Select by class
  • 'tag' — Select by tag name
  • '[attribute=value]' — Select by attribute
  • 'parent child' — Select descendant
document.querySelector('#main');
document.querySelector('.active');
document.querySelector('input[type="text"]');

Example: Select by ID

<div id="header">Welcome!</div>
const header = document.querySelector('#header');
header.style.color = 'blue';
  • Selects the element with ID header and changes its text color.

Example: Select by Class

<button class="submit">Submit</button>
const btn = document.querySelector('.submit');
btn.disabled = true;
  • Disables the first button with class submit.

Example: Complex Selector


<ul>
  <li class="item">Apple</li>
  <li class="item">Banana</li>
</ul>
        
const firstItem = document.querySelector('ul .item');
firstItem.textContent = 'Orange';
  • Finds the first .item inside a ul and changes its text.

Example: Attribute Selector

<input type="email" name="userEmail">
const emailInput = document.querySelector('input[type="email"]');
emailInput.placeholder = 'Enter your email';
  • Selects the email input and sets a placeholder.

Alternate Uses & Tips

  • Can be used to select elements for event listeners:

const link = document.querySelector('a.help');
link.addEventListener('click', function(event) {
  alert('Help clicked!');
});
  • Use document.querySelectorAll() to select all matching elements (returns a NodeList).

Limitations & Best Practices

  • Returns only the first match—use querySelectorAll() for multiple elements.
  • If no match is found, returns null—always check before using the result.
  • Keep selectors specific but not overly complex for readability and performance.

Summary

  • document.querySelector() is a versatile, modern way to select DOM elements.
  • Supports all CSS selectors for powerful, flexible queries.
  • Ideal for dynamic UI manipulation and event handling.
